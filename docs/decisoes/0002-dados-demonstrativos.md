# ADR 0002 — Rede demonstrativa transparente

Status: aceito — 2026-10-28

Como fontes públicas não oferecem grade e geometrias atuais completas, nomes confirmados podem ser usados com proveniência própria, enquanto paradas intermediárias, geometrias e horários são sintéticos. A aplicação exibe essa distinção no resultado e nunca chama a simulação de GPS real.
